
# IT Help Desk SLA Breach Prediction – Excel Analysis

## Project Overview

As part of my IT Help Desk SLA Breach Prediction project, I worked on data analysis and dashboard development using Microsoft Excel.

The main purpose of this phase was to analyze IT Help Desk ticket data, understand ticket management performance, evaluate SLA compliance, identify SLA breaches and visualize important operational metrics.

I used the Balanced Scenario dataset to perform the analysis and developed an interactive Excel dashboard to present the overall performance of the IT Help Desk system.

## Objectives

- Analyze IT Help Desk ticket data.
- Understand ticket volume and distribution.
- Analyze ticket status, priority and issue types.
- Evaluate First Response SLA and Resolution SLA performance.
- Identify SLA-compliant and SLA-breached tickets.
- Analyze average response and resolution times.
- Understand ticket backlog and agent group performance.
- Develop an interactive Excel dashboard.

### 3. SLA Performance Analysis

I focused on two important SLA measurements.

#### First Response SLA Analysis

First Response SLA measures whether a ticket receives its initial response within the defined SLA time.

I analyzed:

- Tickets that met the First Response SLA.
- Tickets that breached the First Response SLA.
- First Response SLA compliance percentage.
- First Response SLA breach percentage.
- Average response time.

#### Resolution SLA Analysis

Resolution SLA measures whether a ticket is resolved within the defined SLA time.

I analyzed:

- Tickets that met the Resolution SLA.
- Tickets that breached the Resolution SLA.
- Resolution SLA compliance percentage.
- Resolution SLA breach percentage.
- Average resolution time.

### 4. KPI Analysis

I created KPI cards to provide a quick overview of overall IT Help Desk performance.

| KPI | Value |
|---|---:|
| Total Tickets | 1,515 |
| Open Backlog | 927 |
| Resolution SLA Breach Rate | 1.52% |
| First Response SLA Breach Rate | 3.70% |
| Resolution SLA Compliance Rate | 98.48% |
| First Response SLA Compliance Rate | 96.30% |
| Average Resolution Time | 140.9 Minutes |
| Average Response Time | 32 Minutes |

#### KPI Explanation

- **Total Tickets:** Total number of tickets included in the analysis.
- **Open Backlog:** Number of tickets that are still open or pending.
- **Resolution SLA Breach Rate:** Percentage of tickets that exceeded the defined resolution SLA.
- **First Response SLA Breach Rate:** Percentage of tickets that exceeded the defined first response SLA.
- **Resolution SLA Compliance Rate:** Percentage of tickets resolved within the defined SLA.
- **First Response SLA Compliance Rate:** Percentage of tickets that received their first response within the defined SLA.
- **Average Resolution Time:** Average time taken to resolve tickets.
- **Average Response Time:** Average time taken to provide the first response.

### 5. Dashboard Development

After completing the analysis, I developed an interactive Excel dashboard to bring all important metrics and visualizations together in one place.

#### Dashboard KPI Cards

- Total Tickets

- Resolution SLA Breach Rate
- First Response SLA Breach Rate

- First Response SLA Compliance Rate
- Average Resolution Time
- Average Response Time

#### Dashboard Charts and Visualizations

1. **SLA Priority Status:** Displays SLA performance across different ticket priority levels.
2. **Issue Type Distribution:** Shows ticket distribution across different issue categories.
3. **SLA Compliance and Breach Analysis:** Compares SLA-compliant and SLA-breached tickets.
4. **Ticket Volume by Channel:** Shows ticket distribution based on source or channel.
5. **Ticket Status Analysis:** Displays ticket distribution based on status.
6. **Ticket Volume by Agent Group:** Shows ticket distribution among different agent groups.
7. **SLA Resolution Time Analysis:** Helps understand ticket resolution performance.

### 6. Interactive Dashboard Filters

I added slicers to make the dashboard interactive and allow users to explore data based on different conditions.

- **Created Time:** Filters tickets based on creation date or time period.
- **Source:** Filters tickets based on their source or channel.
- **Priority:** Analyzes tickets based on priority levels.
- **Topic:** Filters tickets based on issue categories.
- **Agent Group:** Analyzes ticket performance across different agent groups.

These filters help explore specific ticket categories and understand SLA performance across different selections.
